1. Evolution of the Web: Web 1.0 vs. Web 2.0 vs. Web 3.0

Dimension Web 1.0 (Read-Only Web) Web 2.0 (Read-Write / Social Web) Web 3.0 (Read-Write-Execute / Semantic Web)
Core Focus Static web pages, passive information consumption. User-generated content, collaboration, social networking. Machine-readable data, decentralization, intelligence, semantic ontologies.
Interaction One-directional (Webmaster → User). Bidirectional & Multi-directional (User ↔ User). Context-aware, autonomous AI agents, trustless peer networks.
Tech Stack HTML, basic CSS, CGI scripts. AJAX, Javascript frameworks, REST APIs, Cloud databases. RDF, OWL, SPARQL, Blockchain, IPFS, Smart Contracts, AI/ML.

2. Web 2.0: Interactive and Social Web

Coined by Dale Dougherty and popularized by Tim O'Reilly in 2004, Web 2.0 refers to web applications that emphasize user-generated content, ease of use, participative culture, and interoperability.

2.1 Core Pillars of Web 2.0:

  • Blogs: Chronological personal or corporate journals with commenting mechanisms (e.g., WordPress, Medium).
  • Wikis: Collaborative knowledge repositories where any authorized user can create, edit, and link hyperlinked pages (e.g., Wikipedia).
  • Social Networking Platforms: Graph-based platforms facilitating social connections, media sharing, and real-time interaction (LinkedIn, X, Facebook).

2.2 Enabling Technologies Behind Web 2.0:

  • AJAX: Facilitates seamless background updates without full page refreshes.
  • RSS (Really Simple Syndication): An XML-based format allowing web publishers to syndicate content feeds automatically to subscribed aggregators.
  • Ruby on Rails (RoR): Server-side web framework popularizing "Convention over Configuration" and rapid MVC scaffolding.
  • Open APIs (RESTful Web Services): Exposing endpoints using JSON over HTTP allowing third-party developers to integrate services (e.g., Google Maps API, Stripe payment gateway).

3. Web 3.0: Semantic Web, Widgets, Mashups & RDF

3.1 The Semantic Web

Proposed by Sir Tim Berners-Lee, the Semantic Web aims to make web data machine-understandable so computers and software agents can process, infer, and connect disparate data sources intelligently.

3.2 RDF (Resource Description Framework)

RDF is the standard data model for the Semantic Web. It represents statements about resources as Triples consisting of three parts:

RDF Triple Structure:
(Subject — Predicate — Object)

Example:
• Subject: https://college.edu/faculty/dr_smith (URI)
• Predicate: http://xmlns.com/foaf/0.1/teaches
• Object: "Web Technology CS35302"

RDF triples form a directed labeled graph across the global web. The graph is queried using SPARQL (SPARQL Protocol and RDF Query Language).

3.3 Widgets and Mashups

  • Widgets: Portable, self-contained interactive components embeddable into any webpage (e.g., weather widget, live stock ticker).
  • Mashups: Composite web applications that seamlessly aggregate data or functionality from two or more distinct open APIs into a unified user interface (e.g., combining Real Estate listings with Google Maps to show home locations and crime rates).

4. Web-Based Information Systems, Search Engines & Recommenders

4.1 Search Engine Architecture

Modern search engines process billions of queries through three foundational stages:

  1. Web Crawling (Spiders/Bots): Automated bots (e.g., Googlebot) systematically discover and download pages by following hyperlinks across the web graph.
  2. Indexing: Parses downloaded HTML, extracts terms, eliminates stop words (e.g., "the", "and"), stems words, and builds an Inverted Index (a lookup dictionary mapping keywords to the list of document IDs containing them).
  3. Ranking & Retrieval: Evaluates query matches using algorithmic scoring:
    • TF-IDF (Term Frequency - Inverse Document Frequency): Evaluates term relevance within a document relative to the whole corpus.
    • Google PageRank: Evaluates link popularity by treating inbound hyperlinks as recursive votes of credibility.

4.2 Recommender Systems

Algorithms that predict user preferences and suggest relevant items (e.g., Netflix movies, Amazon products):

  • Content-Based Filtering: Recommends items similar to those the user has liked in the past based on product features (e.g., genres, actors, keywords).
  • Collaborative Filtering: Recommends items based on collective behavior and similarities across users:
    • User-Based: Finds users with similar rating histories and recommends what they enjoyed.
    • Item-Based: Recommends items frequently purchased together by the community.
  • Hybrid Systems: Blends content-based and collaborative algorithms to overcome cold-start issues (e.g., new items with no ratings).

5. Modern Web Paradigms: Blockchain, Edge Computing & Dark Mode

5.1 Benefits of Blockchain in Web Development:

  • Decentralized Authentication (Web3 Login): Users authenticate via cryptographic cryptographic wallets (e.g., MetaMask) without passwords or centralized OAuth trackers.
  • Tamper-Proof Audit Trails: Immutable public ledgers guarantee transparency for supply chains, transactions, and voting.
  • Smart Contracts: Self-executing agreements enforced directly in code without intermediaries.

5.2 Edge Computing in Web Architectures:

Traditional cloud architecture centralizes computation in massive data centers far from users. Edge Computing moves serverless compute logic (e.g., Cloudflare Workers, AWS Lambda@Edge) and caching directly to Content Delivery Network (CDN) edge nodes physically adjacent to the client.

Key Benefits: Drastically reduced round-trip latency (sub-10ms response), decreased central server bandwidth, and high resilience against distributed Denial-of-Service (DDoS) attacks.

5.3 Dark Mode in Web Development:

Modern web standards natively support system-level theme switching through CSS media queries:

@media (prefers-color-scheme: dark) {
    body {
        background-color: #0f172a;
        color: #f8fafc;
    }
}

Benefits: Significant battery power savings on OLED and AMOLED displays, reduced eye fatigue in low-light environments, and higher accessibility standards (WCAG contrast ratios).
